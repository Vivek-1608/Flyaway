# FlyAway ✈️

A full-stack travel accommodation booking platform inspired by Airbnb, where users can explore unique stays, create listings, review properties, and manage accounts.

---

## 🌐 Features

- Explore travel destinations and stays
- Create, edit, and delete listings
- User authentication and authorization
- Add reviews and ratings
- Image upload support
- Responsive UI with modern design
- Flash messages and session handling
- MongoDB Atlas integration

---

## Frontend
